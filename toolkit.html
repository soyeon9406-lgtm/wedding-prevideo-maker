사진·PDF·링크, 폰 안에서 정리

파일을 어디에도 올리지 않는 도구 7가지. 회원가입도, 서버 전송도 없어요.

서버 전송 0무료설치 없이 사용
이 앱은 어떻게 동작하나요?

모든 사진과 PDF는 기기의 브라우저 메모리 안에서만 열리고, 어떤 파일도 서버로 전송되지 않습니다. EXIF·위치정보는 캔버스로 다시 그리는 과정에서 사라지고, 링크 정리는 주소 문자열만 다룹니다. PDF 변환·QR·ZIP 기능의 라이브러리만 처음 사용할 때 공개 CDN에서 내려받습니다. 인터넷이 끊겨도 이미 열어 둔 페이지에서는 대부분의 기능이 그대로 동작합니다.

로컬 툴킷 · 개인정보를 넣지 않는 범용 도구 · GitHub Pages 같은 정적 호스팅에 그대로 올려 쓸 수 있습니다.

EXIF 제거 · 모자이크

위치·기기 정보를 지우고, 가릴 곳을 문질러 지우세요

손가락(또는 마우스)으로 가릴 곳을 드래그하면 그 영역이 픽셀 블록으로 덮입니다. 블록 크기는 다음에 그릴 때 적용됩니다.

저장할 때 캔버스로 다시 인코딩하기 때문에 촬영 위치(GPS), 촬영 기기, 촬영 시각, 소프트웨어 정보가 모두 사라집니다. 얼굴·계좌번호·주소가 보이는 부분은 모자이크로 덮어 두세요.

링크 추적 파라미터 제거

공유 링크에 붙은 추적 꼬리표를 잘라냅니다

utm_*, xmt, igshid, fbclid, gclid, mc_*, ref 등 60여 종의 추적 키를 제거합니다. 쿠팡의 productId·itemId·vendorItemId처럼 링크가 동작하는 데 꼭 필요한 값은 남겨 둡니다.

PDF ↔ 이미지 변환

PDF 페이지를 사진으로, 사진을 PDF 한 장으로

변환은 브라우저 안에서 이뤄지고 PDF는 어디에도 전송되지 않습니다. 첫 변환 때만 라이브러리를 공개 CDN에서 내려받습니다.

이미지 압축 · 포맷 변환

품질을 낮추면 얼마나 줄어드는지 바로 비교

-원본
-결과
-절감

JPG·WebP는 품질 값을 낮출수록 용량이 줄고 화질이 조금씩 부드러워집니다. PNG는 무손실이라 품질 슬라이더 대신 색 구성에 따라 용량이 정해집니다.

QR 코드 생성

링크·텍스트·Wi-Fi를 만료 없이 이미지로

QR 안에는 입력한 내용만 담기고, 만료 기간이나 접속 기록이 생기지 않습니다. Wi-Fi QR은 손님이 카메라로 찍으면 비밀번호 입력 없이 접속할 수 있어요.

SNS 비율 리사이즈

잘리지 않게 여백이나 블러 배경으로 채우기

인스타그램 1:1·4:5, 유튜브 썸네일 16:9, 릴스·스레드 9:16 비율로 저장됩니다. 긴 변 기준 1080px(16:9는 1920px)로 맞춰 SNS 업로드 권장 크기에 가깝게 만듭니다.
