# 셀프 식전영상 메이커

브라우저에서 바로 만드는 빈티지 필름 감성 식전영상 웹앱입니다.
설치도, 로그인도, 서버도 필요 없습니다. `index.html` 한 파일로 동작합니다.

## 쓰는 법

1. GitHub Pages 주소를 연다.
2. 사진과 짧은 영상(MP4·MOV·WebM)을 고르고 순서를 정한다.
3. 아래 타임라인에서 컷 순서·길이·배속을 다듬고, 자막을 끌어 시간과 길이를 맞춘다.
4. 신랑·신부 이름과 예식일을 넣는다(비워 두면 `신랑 · 신부`로 표시됩니다).
5. 미리보기로 확인한 뒤 영상으로 내려받는다.

사진과 이름은 모두 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.

## 편집 기능

- **타임라인** — 인트로·컷·엔딩이 한 줄로 보이고, 컷을 끌어 순서를 바꾸고 오른쪽 끝을 끌어 길이를 바꿉니다.
- **컷 편집** — 컷마다 길이(0.5~30초)와 배속(0.5x~2x)을 따로 지정합니다. 배속은 사진의 켄번즈 움직임과 영상 재생 속도에 함께 적용됩니다.
- **스티커(이미지) 오버레이** — PNG·JPG 이미지를 올려 영상 위에 얹습니다. 미리보기에서 끌어 옮기고, 오른쪽 아래 손잡이로 크기, 위쪽 손잡이로 회전을 바꾸며 투명도도 조절합니다. 타임라인의 **스티커** 트랙에서 보이는 구간을 맞추고, 내보낸 영상에도 그대로 그려집니다.
- **화면 비율 16:9 ↔ 9:16** — 상단 `16:9 가로` / `9:16 세로` 버튼으로 식장 스크린용 1920×1080과 릴스·쇼츠용 1080×1920을 한 번에 바꿉니다. 미리보기 비율과 내보내기 해상도가 함께 바뀌고 자막·스티커 위치도 비율에 맞춰 유지됩니다.
- **컷 분할·구간 트림** — 재생 위치(빨간 선)에서 `✂ 컷 분할`을 누르면 그 컷이 둘로 나뉘어 각각 순서·길이·배속·삭제를 다룰 수 있습니다. 영상 컷은 컷 편집 인스펙터의 `시작`·`끝` 슬라이더로 원본의 원하는 구간만 골라 씁니다.
- **자막 트랙** — 컷 트랙 아래에 자막 블록이 나옵니다. 끌어서 시작 시간을 옮기고, 양 끝을 끌어 길이를 조절합니다. `드래그로 자막 추가`를 켜 두고 빈 곳을 끌면 그 구간에 자막이 바로 생깁니다.
- **2분할 컷** — 컷을 선택해 `좌우 2분할`을 켜면 왼쪽·오른쪽 슬롯에 사진이나 영상을 나란히 놓습니다. 기본은 전체 화면 한 컷입니다.
- **원클릭 일괄 적용** — 폰트·글자 디자인·크기·위치를 모든 자막과 제목에 한 번에 입힙니다. 미리보기에서 글자를 끌어 옮기거나 모서리 손잡이로 키운 직후 뜨는 버튼으로도 적용할 수 있습니다.
- **내 스타일 템플릿** — 지금 서식(폰트·디자인·크기·위치·필터·그레인)을 이름 붙여 이 브라우저에 저장하고, `+ 새 프로젝트`로 빈 타임라인을 연 뒤 불러와 대사·컷은 그대로 두고 서식만 입힐 수 있습니다.
- **영상 내보내기** — 1920×1080, 브라우저에 따라 MP4(H.264) 또는 WebM으로 저장합니다. 동영상 컷은 소리 없이 화면만 사용하고, 배경음악만 함께 녹음됩니다.

## 구성

- `index.html` — 앱 전체(HTML·CSS·JS 단일 파일)
- `.nojekyll` — GitHub Pages가 파일을 그대로 서빙하도록 하는 표시 파일
